# Evaluation Corpus

`dataset.jsonl` contains the 80 evaluation cases approved by the project owner
on 2026-09-29. It is the version-controlled gold dataset for retrieval,
generation, agent, citation, and MCP evaluation.

## Composition

- 30 English single-turn answerable cases.
- 30 French single-turn answerable cases.
- 10 unsupported cases, split evenly between English and French.
- 10 multi-turn cases, split evenly between English and French.
- 64 development and 16 held-out cases, stratified across all groups.

## Maintenance Procedure

For every case, check:

1. The question is natural and represents a useful student request.
2. The expected answer contains only facts supported by the referenced source.
3. French wording and translations are correct.
4. Every `relevant_source_id` is necessary and sufficient.
5. The expected tool behavior is appropriate.
6. The case belongs in its assigned category and split.

Every case is marked `review.status = "approved"` with `project_owner` as the
reviewer. Changes to questions, expected answers, source IDs, splits, or tool
behavior require explicit project-owner approval. Held-out answers must not be
used to tune retrieval configuration.

Run these deterministic checks after any edit:

```powershell
python scripts/evaluation/build_source_manifest.py --check
python scripts/evaluation/validate_dataset.py
python -m pytest tests/evaluation -q
```

The approved `dataset.jsonl` is intentionally not generated by a script. This
prevents a maintenance command from silently overwriting reviewed gold data.
The original notebooks are preserved as historical references and are not run
or compared as evaluation baselines.
